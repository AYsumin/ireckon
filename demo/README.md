# 给同行的 demo：验证结构，不验证才华

这份 demo 的目的只有一个：**让别人不用信我们的话，自己跑一遍，看这套结构立不立得住。**

它不需要 API key、不联网、不装第三方包。

```bash
python demo/offline_demo.py
```

退出码 0 = 结构成立；非 0 = 具体哪一条不成立，输出里写着。

---

## 它验证什么

| 项 | 它在回答什么问题 |
| --- | --- |
| 五层表 | 时 / 日 / 周 / 月 / 年 的表和外键能不能一次建起来 |
| 检索 | 给定 24 条记忆、18 个问题，目标记忆能不能进 top-5 |
| 断崖截断 | 用"分数掉到首条 60% 就停"能省多少条 / 多少 token，会不会掉准确率 |
| token 预算 | 一次注入能不能稳定压进 198 token |

**全部数据是合成的，不含任何真实用户数据。**

## 它不验证什么

```
生成质量     要真模型，本 demo 用假数据不跑 LLM
多跳能力     已知弱：5 条召回 35%，要 40 条才追平（见主 README §6）
长文处理     只处理 20–45 字的原子事实
线上稳定性   没有并发、没有断电、没有跑够 30 天
```

---

## 关于跑出来的数字，先说清楚

本 demo 里 18/18 看起来漂亮，原因是**题面与记忆有部分字重合**——这是为了让它可复现，不是为了自夸。

**真实情况（200 道强制改写的题）：**

| 检索方式 | Recall@5 |
| --- | --- |
| 纯 BM25（本套件默认） | **67.5%** |
| 纯向量 | 80.5% |
| RRF 融合 | 85.5% |

**所以：这套结构能跑，但它的字幕面检索在"换说法"上会掉。**
想让它更准，就开 `ireckon/vector_backend.py`（可选，默认关闭）。

```

tests/test_smoke.py    不联网的冒烟测试（比 demo 更底层）
```

跑完 demo，想知道它的边界在哪：

```bash
python tests/test_smoke.py
```
